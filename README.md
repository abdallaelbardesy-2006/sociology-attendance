# 🎓 نظام الحضور الذكي بالـ QR — قسم علم الاجتماع (جامعة عين شمس)

تطبيق ويب (PWA) لتسجيل الطلاب واستخراج كارنيه حضور رقمي **موقَّع ضد التزوير**، مع لوحة تحكم بصلاحيات منفصلة، وماسح كاميرا، وإحصائيات حضور حقيقية لكل مادة ومحاضرة وطالب.

- قاعدة البيانات: **Google Sheets** عبر Google Sheets API v4 (Service Account)
- الاستضافة: **Vercel** + **GitHub**

## الأدوار والصلاحيات (تُفحص على السيرفر في كل طلب)

| الدور | ماذا يرى ويفعل |
|---|---|
| **المشرف العام** (حساب `ADMIN_EMAIL` فقط) | كل شيء: الإحصائيات بكل الفلاتر، الماسح لكل المواد، إدارة الطلاب والكارنيهات، الترقية، إضافة الدكاترة والليدرز وتعطيلهم، سجل العمليات، تأمين الشيت |
| **دكتور مادة** | إحصائيات وكشوف حضور وغياب **المواد المسندة له فقط** + الماسح لمواده فقط |
| **ليدر دفعة** | **الماسح فقط** (لكل المواد أو لمواد فرقة محددة) — لا يرى أي إحصائيات أو بيانات طلاب |

## الحماية ومكافحة الغش

- كلمات المرور مشفرة بـ **scrypt**، وكل حساب جديد يحصل على كلمة مؤقتة يجب تغييرها عند أول دخول.
- جلسة موقعة داخل كوكي `HttpOnly; Secure; SameSite=Strict` لمدة 12 ساعة، تُلغى فوراً عند التعطيل أو تغيير كلمة المرور.
- كارنيه الطالب بصيغة `SOC3|الكود|توقيع HMAC` — لا يمكن توليد كارنيه لطالب آخر بمعرفة كوده، وأي كارنيه مزور يُرفض ويُسجل.
- منع تكرار الحضور (نفس الطالب/المادة/اليوم)، رفض الطلاب الموقوفين، وتأكيد إضافي لطالب من فرقة أخرى.
- اسم المادة والفرقة والترم تُحدد على السيرفر من كود المادة، لا من المتصفح.
- حدود لمحاولات الدخول والتسجيل، honeypot ضد البوتات، منع التسجيل المكرر بنفس الاسم.
- الكتابة في الشيت بصيغة `RAW` (لا حقن معادلات)، وتصدير CSV آمن، و CSP وheaders أمان كاملة.
- كل تبويبات الشيت مقفولة: لا يعدلها إلا مالك الملف وحساب الخدمة.
- سجل عمليات `AuditLog` لكل دخول وتعديل ومحاولة مشبوهة.

## متغيرات البيئة (Vercel → Settings → Environment Variables)

| المتغير | الوصف |
|---|---|
| `GOOGLE_SHEET_ID` | معرّف ملف الشيت |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` / `GOOGLE_PRIVATE_KEY` | بيانات حساب الخدمة |
| `ADMIN_EMAIL` | بريد المشرف العام الوحيد |
| `ADMIN_SECRET_KEY` | كلمة مرور أولية للمشرف العام (تُستخدم فقط إن لم يكن له كلمة مرور مشفرة في الشيت) |
| `SESSION_SECRET` | سر توقيع الجلسات (64+ حرف عشوائي). تغييره يسجل خروج الجميع |
| `QR_SECRET` | سر توقيع الكارنيهات (64+ حرف عشوائي). **لا تغيره** وإلا بطلت كل الكارنيهات |

## هيكل المشروع

```text
api/
  _sheets.js          طبقة البيانات: الطلاب، الحضور، الإحصائيات، الحسابات، التأمين
  _lib/security.js    التشفير، الجلسات، توقيع QR، rate limiting
  _lib/http.js        غلاف موحد: CSRF + تحقق الجلسة والدور + أخطاء آمنة
  _lib/curriculum.js  اللائحة (78 مادة) — المصدر الوحيد على السيرفر
  auth.js  attendance.js  analytics.js  students.js  admins.js  promote.js  setup.js  meta.js
public/
  index.html  admin.html  dashboard.html  js/  css/  sw.js
scripts/
  dev-server.js       سيرفر محلي يحاكي Vercel (--mock لبيانات وهمية)
  test-api.js         74 اختبار أمان وصلاحيات
```

## التشغيل والاختبار محلياً

```bash
npm install
node scripts/dev-server.js --mock     # بيانات وهمية على http://localhost:3000
node scripts/test-api.js              # في نافذة أخرى
```

بدون `--mock` يعمل على الشيت الحقيقي باستخدام `service-account-key.json` و `.env` (كلاهما خارج git).
