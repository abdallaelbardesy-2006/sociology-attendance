# 🎓 نظام الحضور الذكي بالـ QR — قسم علم الاجتماع (جامعة عين شمس)

تطبيق ويب (PWA) لتسجيل الطلاب واستخراج كارنيه حضور رقمي **موقَّع ضد التزوير**، مع لوحة تحكم بصلاحيات منفصلة، وماسح كاميرا يعمل بنظام **المحاضرات من 1 إلى 15 بالترتيب**، وإحصائيات حضور حقيقية.

- قاعدة البيانات: **Google Sheets** عبر Google Sheets API v4 (Service Account)
- الاستضافة: **Vercel** + **GitHub**

## الأدوار والصلاحيات (تُفحص على السيرفر في كل طلب)

| الدور | ماذا يرى ويفعل |
|---|---|
| **المالك** (حساب `ADMIN_EMAIL`) | كل الصلاحيات + إضافة/تعطيل **مشرفين عامين** آخرين |
| **مشرف عام** | كل شيء ما عدا إدارة حسابات المشرفين العامين وحساب المالك |
| **دكتور مادة** | إحصائيات وكشوف **مواده فقط** + الماسح لمواده |
| **ليدر دفعة** | **الماسح فقط** (كل المواد أو مواد فرقة محددة) |

## المحاضرات
- لكل مادة 15 محاضرة في تبويب `Lectures`. لا يعمل المسح إلا داخل محاضرة مفتوحة اليوم.
- "تم إنهاء المحاضرة" يقفلها، والمحاضرة التالية تُفتح في يوم لاحق فقط (المشرف العام يمكنه الفتح الاستثنائي أو إعادة فتح محاضرة أُنهيت بالخطأ).

## الحماية
- كلمات المرور مشفرة بـ **scrypt**، وكلمة مؤقتة إجبارية التغيير لكل حساب جديد.
- جلسة موقعة في كوكي `__Host-` بخصائص `HttpOnly; Secure; SameSite=Strict` (12 ساعة)، تُلغى فوراً عند التعطيل أو تغيير كلمة المرور.
- قفل الحساب 15 دقيقة بعد 6 محاولات خاطئة (محفوظ في الشيت فيعمل على كل نسخ السيرفر)، وزمن رد ثابت لا يكشف البريد المسجل.
- دور المشرف العام الإضافي موقّع (HMAC): تعديل الدور يدوياً في الشيت لا يمنح أي صلاحية.
- كارنيه الطالب `SOC3|الكود|توقيع HMAC`؛ المزور والقديم والمكتوب يدوياً مرفوض ومسجل في سجل العمليات.
- منع تكرار الحضور، رفض الموقوفين، تأكيد إضافي لطالب من فرقة أخرى، وبيانات المادة من السيرفر فقط.
- إمكانية **غلق تسجيل الطلاب** من الإعدادات بعد انتهاء فترة التسجيل.
- حماية CSRF، حدود للطلبات، honeypot، كتابة `RAW` في الشيت، تصدير CSV آمن، عرض كل النصوص كنص عادي.
- CSP مقيدة بملفات محددة + **SRI** لكل مكتبة خارجية + headers أمان كاملة.
- كل تبويبات الشيت مقفولة على حساب الخدمة والمالك، وسجل `AuditLog` لكل العمليات.

## متغيرات البيئة (Vercel → Settings → Environment Variables)

| المتغير | الوصف |
|---|---|
| `GOOGLE_SHEET_ID` | معرّف ملف الشيت (مطلوب) |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` / `GOOGLE_PRIVATE_KEY` | بيانات حساب الخدمة |
| `ADMIN_EMAIL` | بريد المالك |
| `ADMIN_SECRET_KEY` | كلمة مرور أولية للمالك (لا تُستخدم بعد تعيين كلمة مرور شخصية) |
| `SESSION_SECRET` | سر الجلسات وتوقيع الأدوار. تغييره يسجل خروج الجميع ويلغي المشرفين العامين الإضافيين (يُعاد إضافتهم) |
| `QR_SECRET` | سر توقيع الكارنيهات. **لا تغيره** وإلا بطلت كل الكارنيهات |

## هيكل المشروع

```text
api/                   دوال Vercel (كل ملف = endpoint)
  auth.js  attendance.js  lectures.js  analytics.js  students.js  admins.js  promote.js  setup.js  meta.js
  _sheets.js           طبقة البيانات: الطلاب، الحضور، المحاضرات، الإحصائيات، الحسابات، الإعدادات، تأمين الشيت
  _lib/security.js     التشفير، الجلسات، توقيع QR والأدوار، حدود الطلبات
  _lib/http.js         غلاف موحد: CSRF + تحقق الجلسة والدور + أخطاء آمنة
  _lib/curriculum.js   اللائحة (78 مادة)
public/                الواجهات: index (الطلاب) • admin (الدخول) • dashboard (اللوحة) + js/ css/ sw.js
scripts/dev-server.js  سيرفر محلي يحاكي Vercel
tests/                 اختبارات الأمان والصلاحيات + محاكي Google Sheets وبيانات وهمية
```

## التشغيل والاختبار محلياً

```bash
npm install
npm run dev        # بيانات وهمية على http://localhost:3000
npm test           # يشغل سيرفر وهمي و 119 اختبار أمان وصلاحيات
npm run dev:real   # على الشيت الحقيقي (يتطلب .env و service-account-key.json خارج git)
```
